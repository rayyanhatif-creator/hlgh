
# شفرة الكنز — موقع مسابقة البحث عن الكنز

## الملفات
- `index.html`: واجهة المشاركين ولوحة المشرف.
- `schema.sql`: جداول قاعدة البيانات في Supabase.
- `README.md`: دليل التشغيل.

## خطوات الإعداد
1. أنشئ مشروعًا جديدًا في Supabase.
2. افتح SQL Editor ونفّذ محتوى `schema.sql`.
3. من إعدادات API انسخ Project URL والمفتاح العام anon.
4. ضع القيم في بداية كود JavaScript داخل `index.html`.
5. أنشئ حساب المشرف من Authentication > Users.
6. ارفع الموقع إلى استضافة تدعم HTTPS.
7. سجّل دخول المشرف، ثم أضف مراحل المسابقة وأسئلتها وتلميحاتها.

## إعداد المراحل
لكل مرحلة أدخل:
- عنوان المرحلة.
- السؤال.
- الإجابة الصحيحة.
- التلميح.
- مكان الورقة.
- الكلمات المخربطة.
- الجملة الصحيحة.
- رسالة النجاح.
- مكان الكنز للمرحلة الأخيرة.

## تنبيه أمني
هذه نسخة تجريبية. يجب إصلاح حفظ الإجابات السرية وتقوية سياسات صلاحيات قاعدة البيانات قبل نشر الرابط للمشاركين.
